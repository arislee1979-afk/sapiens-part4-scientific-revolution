讀者與問題

這份知識要回答的四個問題

先問再畫：每張圖只回答一個問題；關係表列出圖上放不下的條件與依據。

Q1

科學革命憑什麼突破前現代知識體系？

認識論門檻：把「我們不知道」從個人缺陷升級成體系屬性。

Q2

科學、帝國、資本如何互相供養？

三位一體迴圈：不是三條平行線，而是互相供能的閉環，並有明確排氣口。

Q3

能源與原料「有限」為何沒讓經濟停下來？

限制只在無知：熱能轉動能之後，能源從水庫變成海洋。

Q4

能力暴增之後，快樂與「智人」本身發生什麼事？

兩個開口：快樂的定義未定；「人」的定義即將被改寫。

D1 · 回答 Q1

科學革命的認識論門檻

斷裂點：前現代體系只承認兩種無知；現代科學承認整套體系對最重要的問題無知。 為了讓社會不因此崩潰，又退回兩種「不科學」的支柱。

Mermaid ID：ancient / m1 / m2 / m3 / o1 / o2

從兩種無知到承認無知

閱讀方式：左欄是前現代的兩種無知，中欄是現代科學的三個特徵，右欄是為穩定而退回的兩根支柱。

圖例：實線光束＝推進關係；虛線＝為了維持穩定而退回不科學的前提

D2 · 回答 Q2

科學、帝國、資本的三位一體迴圈

一台會自我增壓的機器：科學給帝國實用知識，帝國給資本殖民地利潤，資本回頭資助遠征與實驗室。 起點是地圖上的空白，排氣口是書中不斷標記的代價。

Mermaid ID：gap / science / empire / capital / cost

互相供養的閉環與它的排氣口

閱讀方式：上方兩道弧是供養方向，外圍粗弓是資本回頭資助，底部是增長不受道德制衡時的出口。

對照來源：關係表另有 5 條配對關係（帝國回報資料與保護給科學、資本投資科學研究、科學提供技術與新能源給資本等）； 本圖只保留迴圈主幹，不把「互相強化」畫成網狀雜訊。

D3 · 回答 Q3

能源、原料與增長：限制只在無知

從水庫到海洋：工業革命前，人類所有活動最終只能吃植物；蒸汽機把熱能轉成動能之後， 能源不再是定量的水庫。農業工業化釋放人力，生產第一次超過需求，於是消費主義接手。

Mermaid ID：old / sun / turn / ocean / mat / agri / surplus / consume

能量轉換如何解開原料與人力限制

閱讀方式：上排由左至右，下排由右往回；底部回廊是利潤再投資，讓整條鏈閉合。

边界提醒：資源沒有上限不代表生態沒有上限。書中把「資源不断增加」與「棲地迅速惡化」分開論證， 本圖只回答前者。

D4 · 回答 Q4 之一

快樂的三種解釋與一個未決前提

不要畫成已解決：生化機制、期望相符、生命有意義三者互不相容； 而它們共同的前提「快樂可由主觀報告測得」本身就可疑。UNKNOWN 出口必須保留。

Mermaid ID：q / body / expect / meaning / buddha / premise / unknown

從「快樂等於什麼」到「能不能測」

閱讀方式：上層三個分支各自成立，中層匯聚成共同前提，最底層是本章明確留下的 UNKNOWN。

不可壓掉的一格：無論畫面怎麼縮，`unknown` 節點與兩條指向它的邊都必須保留； 把這一格改成「答案是更快樂」就是偽造來源沒有的結論。

D5 · 回答 Q4 之二

智人末日的三條路徑

正當性來源：三條路徑都掛在吉爾伽美什計劃下面——「為了治療疾病、挽救性命」是無人能反駁的標準答案， 也因此擋不住。

Mermaid ID：gilgamesh / bio / cyborg / inorganic / replace / unknown

閱讀方式：單一源頭分出三條工程路線，三者在「取代」節點匯合，末端是未定的時間表。
